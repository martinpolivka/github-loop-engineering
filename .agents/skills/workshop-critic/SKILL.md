# Workshop critic

Inspect the actual changed artifacts. Report only blocking or material findings.

Evaluate learning flow, pacing, cognitive load, live-demo reliability, sandbox
truthfulness, future enterprise portability, GitHub product accuracy, workflow
security, accessibility, exact commands, recovery paths, and whether the
full-day experience delivers a coherent end-to-end loop engineering story
rather than a feature tour.
